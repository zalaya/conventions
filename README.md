# Conventions

A collection of reusable skills and coding standards that help coding agents work consistently across projects.

## Install a skill

```bash
# See the skills available in this repository
bunx skills add zalaya/conventions --list

# Install one skill in the current project
bunx skills add zalaya/conventions --skill commit-conventions

# Install one skill globally for your user
bunx skills add zalaya/conventions --skill commit-conventions -g
```

Useful maintenance commands:

```bash
bunx skills update
bunx skills remove commit-conventions
```
